 Positivus – Projet Web

- Description du projet:

Ce projet consiste à réaliser un site web vitrine pour une entreprise fictive nommée Positivus.  
Le site présente différents services, l’équipe, les témoignages des clients ainsi qu’un formulaire de contact.

- Utilisation du stash

Le git stash a été utilisé lorsque des modifications locales n’étaient pas prêtes à être commitées, afin de pouvoir changer de branche sans perdre le travail en cours.

- Résolution des conflits

Lors des fusions entre les branches release, main et develop, des conflits sont apparus, notamment dans certains fichiers du projet.
Ces conflits ont été résolus manuellement en analysant les différentes versions et en conservant le code le plus récent et fonctionnel.
Après la résolution, les fichiers ont été ajoutés et validés avec les commandes git.
Plusieurs autres conflits ont été réglés dont quelques en images dans le dossier captures-ecran.
